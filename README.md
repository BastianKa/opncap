# opncap

Open-source macropad for AI coding agents: 14 hotswap keys, rotary encoder, Hall-effect joystick, round display, microphone, per-key RGB.

| Path | Content |
|---|---|
| `hardware/` | Hardware revisions (`opncap_v0.1` to `opncap_v0.3`). Current work uses **v0.3**, older revisions are archive. Each revision has its own `spec.md` and `features.md`. |
| `software/` | Firmware, protocol, host service and app. `software/spec.md` and `software/features.md` describe the software. |

Status: planning and generated design. Nothing is ordered or tested on real hardware.
