# opncap raw HID protocol v1

Source of truth: `protocol.yaml`. The C header (`../firmware/qmk_userspace/keyboards/opncap/opncap_v0_3/opncap_protocol.h`) and the Python module (`../host/opncap_host/protocol.py`) are generated by `gen.py`; never edit them by hand. CI fails if they are out of date.

Status: built and tested in CI on the host (Python and C against shared vectors). Not tested on real hardware.

## Frame

32 bytes, little-endian.

| Offset | Size | Field | Note |
|---|---|---|---|
| 0 | 2 | magic | `0x4F 0x43` ("OC") |
| 2 | 1 | version | protocol version, currently 1 |
| 3 | 1 | msg | message id |
| 4 | 1 | seq | sequence number; the host increments, the device echoes it in its reply |
| 5 | 1 | len | payload length, 0 to 24 |
| 6 | 24 | payload | zero-padded after `len` bytes |
| 30 | 2 | crc | CRC-16/CCITT-FALSE over bytes 0 to 29 |

CRC-16/CCITT-FALSE: polynomial 0x1021, init 0xFFFF, no reflection, no final xor. Check value of `"123456789"` is `0x29B1`. The final CRC choice is still open for review.

Decoding checks in this order: size, magic, crc, version, length, zero padding.

## Messages

Host to device (commands): `get_version` 0x01, `set_led` 0x02, `set_state` 0x03, `set_agent_state` 0x04, `set_display` 0x05, `set_config` 0x06.
Device to host (events and replies): `ack` 0x70, `version_info` 0x71, `key_event` 0x80, `encoder_event` 0x81, `joystick_event` 0x82, `layer_event` 0x83.

Field layouts and enums are in `protocol.yaml`.

## Tests

```sh
cd software
make test      # generated files up to date, Python tests, C test
```

`tests/vectors.txt` holds shared vectors (valid frames and one invalid frame per error). The Python and the C test both read it, so the two implementations are checked against the same bytes.
